# Spree — issue344

This isolated prototype starts from reviewed main2812c74 (1,977/schema103).
The full inventory covers21 whole Standard identities and133 unique pinned
Java sources. Only Explosive Derailment and Phantom Interference currently have
all mode effects implemented. They are prototype candidates, pending real paid
subset tests, strict actual-parent preservation, naturally drawn Standard games
and independent final-head reviews. The other19 remain gated and in scope.

Every nonempty distinct subset is precompiled in printed order into one immutable
modal program with rebased target groups and summed additional mana. This reuses
the existing modal additional-cost metadata (historically named tiered_costs),
never replaces the base/alternative cost and adds no persistent gameplay state.
The current inventory has at most three branches (seven combinations); the
compiler represents up to six branches (63), rejecting larger definitions before
admission. The resulting subset index is immutable for target binding/payment/
resolution/copies and owned rollback. No zero or duplicate subset is emitted.

Authoritative [Wizards release notes](https://magic.wizards.com/en/news/feature/outlaws-of-thunder-junction-release-notes)
require chosen additional costs even when the base mana cost is waived. Actual
native/public acceptance has not run yet. Three compiler methods pass against
the first prototype; this is not gameplay acceptance or a merged coverage claim.
