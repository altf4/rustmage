# Eight further complete Adventure pairs

Issue [277](https://github.com/altf4/rustmage/issues/277) implements Beanstalk Wurm, Beorn Reluctant Host, Bellowing Bruiser, Beluna's Gatekeeper, Bofur Reliable Guardian, Ishgard the Holy See, Velvetwing Butterflies and Woodland Acolyte as complete printed pairs. Both faces must compile their entire text. Unknown reminders and residual clauses reject the whole physical card; no card-name admission whitelist is used.

The candidate has 1,825/5,164 executable Standard identities, with 3,339 still gated. It retains all thirteen Omen pairs, 87 token recipes and one emblem, and now has 27 Adventure helpers and 5,311 total definitions. The full Standard migration remains incomplete.

A checked per-player `u64` counter tracks remaining additional land plays granted this turn. The original one-land allowance remains independent. Each actual extra land play consumes one grant; separate resolved spells accumulate. The counter is public in `PlayerView.extra_land_plays_remaining` under observation schema 81. Both players' grants expire at cleanup, including a grant cast on the opposing turn through Whirlwing. Lands still require the actor's own main phase, priority and an empty stack. The same quota applies to land Adventure normal play from exile.

`Instruction::TopLibrary` reuses exact-incarnation, owner-safe targeted library movement and publishes only the existing public movement payload. It adds no private continuation or object state. Typed target plans express the other complete effects: distinct up-to-two cannot-block targets, opponent creature mana value at most three, own artifact-or-creature protection, own artifact/enchantment graveyard returns, and one-or-two creature taps. Targets are revalidated at resolution. A sole illegal target counters the Adventure by the rules and creates no exile permission; partial legal target groups resolve for their surviving targets.

Seven native groups cover both seats, all eight paid insets and exact normal recasts, accumulating/interleaved extra lands, off-turn grants and expiration, cardinality/duplicates/partial resolution, owner/type/mana-value/incarnation targets, artifact protection cleanup, and late arithmetic overflow rollback. Every action checks raw/index replay, snapshots, parent-dropped children, wrong actors, stale revisions and both observations. The initial full inherited native suite passes 1,691 unit and twelve integration tests; the seven additional groups pass in 0.33 seconds. Final combined native/lint, fresh public API and Standard workloads remain pending.

The canonical parent audit preserves 5,295 of the parent's 5,303 definitions; exactly the eight previously unsupported ordinary rows change, and eight new immutable Adventure definitions are added. All 5,303 existing color entries, 87 token recipes and 793 existing typed helper arms are preserved. The combined manifests contain 1,697 source records across 578 unique Java files; complete checkout bytes and pinned Git objects agree at `492369c7844b8d76479f0393ff9eb6b0b0cf30d7`. The eight new entries audit 48 direct source/semantic dependency files. This does not claim every transitive Java dependency has been translated.

Ordinary acceptance is `python3 examples/standard_adventure_land_targets.py --library PATH --games 100`. Each game uses legal sixty-card Standard decks, actual land-funded casts, the complete inset effect, the same physical card's normal play, a real original-source attack (or Ishgard mana production) and a natural terminal outcome. The public driver is implemented but has not yet passed; its pending status is explicit.

This branch currently depends on the frozen Omen union, which is separately under review. Two independent nonauthor reviews of the final published commit are required before merge.
