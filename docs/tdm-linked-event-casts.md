# Linked exile and damage-event free casts

This engine checkpoint adds the two remaining event-context dependencies without
changing ordinary TDM definitions or admissions. It builds on the four groups in
`tdm-event-contexts.md`. The paired evidence file records source/Oracle/Java pins,
all final matching-input reports and the retained earlier failures.

`RevealTargetHandMayExileLinked` reveals the entire targeted hand before filtering
and offers an optional nonland choice. A successful exile writes an exact link
for the source incarnation and acquired ability pair. The existing mandatory
Null Summoner path keeps its separate link vector and mandatory semantics.

`CreateSizedTokensForLinkedExileOwners` samples only currently linked cards still
in exile at resolution. Under CR607.3, copied first abilities sum all linked mana
values; each distinct owner creates one Spirit of that full size. Official
Skyclave release notes confirm this multiowner case. A copied leave trigger can
create again; no-link and stale-link outcomes create nothing. Zero still creates
a0/0 token that may trigger entry observers before state-based actions.

A new private replacement work frame retains processed and remaining owner
batches. It completes all APNAP token replacement choices before allocating and
committing one simultaneous entry batch. Nested group/recipe vectors have owned
memory accounting. The entry continuation handles both synchronous commit and
choice-suspended entry; ordinary single-owner copy creation retains its API.

`ExileDamageEventLibraryCastFree` reads the frozen actual damaged player and
amount. It exiles available top cards, remembers only successful new exact exile
incarnations, and reuses the immediate free-cast protocol. Each spell must have
mana value at most the damage amount; there is no shared budget. The existing
exclusive maximum represents the inclusive bound asX+1 where possible. Large
quantities remain wide until bounded by the finite library. FreeX is0 and
mandatory additional costs still apply. Finishing grants no later permission.
