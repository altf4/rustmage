# Aetherdrift engine dependency checkpoint

All 276 pinned Oracle/main XMage implementation bodies and current typed definitions have been read across four disjoint audits. The per-card source pins, obligations, existing primitives, concrete gaps and required observable outcomes are in `docs/aetherdrift-audit/`. This is a dependency audit; actual per-card rules proofs and further reusable-source review remain pending. Starting admission remains 119/276 with no new card admission.

The following full dependency inventory deliberately retains each audit ID (overlaps will share one implementation owner). All identified engine changes and their focused/shared contract proofs and independent reviews must finish before ordinary DFT card authorship.

- [ ] **max_speed**: Generalize live speed scalar and max-speed qualifications across static stats/keywords, trigger grants, graveyard activation/cast and draw replacements. Preserve layer-six grants rather than merely adding a resolution if.
- [ ] **exert_cost**: Add exert as a paid activation cost with exact incarnation and controller next-untap-step skip; it is not an effect and survives countering.
- [ ] **participant_events**: Dispatch a crew/saddle payment event per contributing creature with exact Mount/Vehicle as non-targeted event object and declaration phase/controller context.
- [ ] **contribution_toughness**: Allow crew/saddle contributions using live toughness instead of power, in funding, incremental selection and commitment; use effective available abilities.
- [ ] **saddle_target**: Mark exact target Mount saddled until cleanup as a resolving effect independent of a Saddle activation/payment.
- [ ] **static_mount_vehicle_union**: Live controller-qualified Mount OR Vehicle modifier without duplicate bonuses for both subtypes.
- [ ] **artifact_spell_or_activation_mana**: Add exact ArtifactSpellOrActivation quality; existing ExceptNonArtifactSpells incorrectly permits Purpose::Other.
- [ ] **offturn_creature**: Conditional layer-four addition of creature type when active player differs from source controller; retain intrinsic vehicle P/T.
- [ ] **exhaust_activation_event**: Trigger on committing an actual Exhaust activation independent of outcome and source permanent type.
- [ ] **controlled_duration_combat_lock**: Linked control effect and cannot-attack/block rule last only while resolving controller continuously controls exact source, irreversibly expire on loss of source control.
- [ ] **counter_filtered_grant**: Grant EOT keywords to snapshot of controlled creatures with ANY counters, including sparse named counters, not just +1/+1.
- [ ] **captured_defender_attack_group**: One trigger for a declaration attacking observer controller, carrying exact group of attacking creatures for EOT -1/-0.
- [ ] **nonland_name_activation_tax**: As-enters nonland card-name choice plus generic activated-ability tax on any source with same rules name, including mana abilities and nonbattlefield activations.
- [ ] **remove_keyword_group**: Remove indestructible only from frozen creature OR Vehicle recipient group, then destroy that group with ordinary replacement/indestructible semantics.
- [ ] **reduce_target_controller_speed**: After bounce, compare target pre-move controller speed with every other player, decrement strictly leading speed by one with floor one.
- [ ] **return_then_animate**: Return target artifact then animate actual resulting incarnation permanently if Vehicle; preserve successful move identity across entry choices/replacements.
- [ ] **untap_nonland_group**: Untap all controlled nonland permanents, including artifacts/enchantments/planeswalkers that are not creatures.
- [ ] **as_enters_copy**: Optional nontargeted as-enters copy of controlled artifact OR creature, before entry choices/counters/ETB; physical card keeps identity and changes copiable recipe.
- [ ] **own_spell_target**: Support unqualified any spell you control target. Existing YourSpellKinds uses u8 mask and requires intersection, so zero never matches and255 misses Battle256-only spells.
- [ ] **speed-value**: No StatValue for controller/player speed. Add generic live quantity to actual/speculative worlds and Item AmountValue via Stat. Reuse SourceConditionalKeywords, StatExpr, KeywordGrant, StepGuard::Expression for max-speed effects.
- [ ] **graveyard-max-speed**: SourceMaxSpeedActivation enumeration in visit_source_grants currently requires giver.zone == Battlefield; max-speed graveyard activations require zone-aware grant/guard availability, affordability and ownership.
- [ ] **exhaust-event**: No ExhaustAbilityActivated trigger qualification. Emit only on actual activation commitment (not failed announcement, copying, resolution).
- [ ] **caster-off-turn**: DuringOpponentsTurn checks active player against observer controller; Adrenaline requires actual spell caster != active player, any-player cast, and fixed caster damage recipient. Add distinct event qualification, never change existing wrapper semantics.
- [ ] **capped-name-exile-search**: General choose-card-name (all legal names) then optional graveyard/hand/library search capped across all three zones, exiling at most four without replacement draws. Existing CoverUpSearch is based on graveyard choice, unbounded and draws for hand exiles.
- [ ] **untargeted-graveyard-kind-subtype**: Need nontargeting mandatory resolution choice of creature OR Vehicle from entire own graveyard after milling (not only newly milled cards); existing RecoverMilled supports Permanent/Land only and selects from milled batch.
- [ ] **discard-event-amount**: Discard batch count is already retained for PutDiscardCounters/DamageDiscardAmount but no general AmountValue::DiscardEventCount for CreateTokensScaled. Add captured quantity or specialized generic token-from-discard instruction.
- [ ] **embalm-grant**: No embalm: temporary exact-graveyard activation grant priced from printed mana cost, sorcery timing, exile source cost, copiable white/Zombie/no-mana-cost token exceptions. CopyExceptions currently lacks those general exceptions.
- [ ] **destruction-result**: Demonic Junker needs simultaneous up-to-one own/one enemy creature destruction and one +2 source counter effect conditional on actual successful destruction of an own creature. Do not infer from selected target or final graveyard result alone.
- [ ] **cost-union-kind-subtype**: SacrificeFilter combines kind and subtype conjunctively; cannot express creature OR Vehicle, Mount OR Vehicle. Generalize typed cost/filter predicates with OR while preserving affordability and speculative reservation.
- [ ] **after-main-combats**: Existing AdditionalCombat increments count consumed only at EndCombat; Full Throttle needs two inserted combat phases immediately after the current main phase (including Main2), no inserted main phase, and a source-independent begin-each-combat trigger through cleanup untapping all current creatures that attacked this turn.
- [ ] **caster-foreign-owned**: CastFilter::NotOwnedByYou compares owner to observer controller; Gonti needs owner != actual caster and token created by actual caster. Add separate filter rather than changing inherited semantics.
- [ ] **combat-foreign-face-down-play**: Reuse PlayerDamaged creature filter + captured controller, but add source-independent permanent foreign face-down exile/play permission for exact top-card incarnation, actor-specific look permission and any-mana spending for spells. Existing face-down play primitives are subtype-gated/source controller/self library.
- [ ] **capped-rummage**: Existing DiscardAnyDraw supports any number/all and DiscardUpToOneDraw caps one; add bounded optional discard 0..N then draw actual completed count (Greasewrench N=2).
- [ ] **delayed-target-dies**: Grim Javelineer creates delayed death trigger controlled by resolving trigger controller, not ability granted to creature. Existing GrantUntilEndTurn queues SelfDies under dying creature controller, so it is not equivalent. Generalize exact target delayed-death registration (ManifestDreadWhenTargetDies has narrow behavior).
- [ ] **sacrifice-cost-facts**: Hellish Sideswipe needs frozen subtype of actual additional-cost sacrificed permanent and conditional draw after destruction. Existing scalar sacrifice facts capture power/mana value but no generic paid Vehicle predicate.
- [ ] **combat-only-token-requirement**: Howlsquad creates token at begin combat and requires that exact actual token to attack this combat if able, including after source departure. Generic keyword MUST_ATTACK lasts too long unless temporary combat-expiring requirement is added.
- [ ] **sacrifice-or-discard-fallback**: Momentum Breaker requires opponent sacrifice a creature/Vehicle if able, otherwise mandatory discard; existing optional ChooseObjects skip means decline not inability and must not supply fallback incorrectly. Add explicit can-pay/failure branch using union predicate.
- [ ] **speed-player-damage**: Outpace Oblivion needs damage 2 to each player whose own speed is <4. Add generic per-player speed predicate/scalar or narrow typed effect; do not evaluate only controller speed.
- [ ] **filtered-mass-return-delayed-sacrifice**: Push the Limit needs simultaneous own graveyard Mount OR Vehicle return with exact successful entrants remembered for next-end-step delayed sacrifice. Existing ReturnOwnedGraveyardNonlandPermanents and ReturnGraveyardCreatures cannot filter arbitrary subtype union or schedule these delayed sacs; Mobilize only token results.
- [ ] **post-mill-target-threshold**: Quag Feast targets creature/planeswalker/Vehicle before milling; compare current target mana value with current controller graveyard size AFTER actual mill then conditionally destroy. Existing target-time max_mana would be wrong. Add conditional typed instruction using target current facts.
- [ ] **crew-saddle-participant-event**: No event for this creature paying another object crew/saddle cost during own main. Emit participant event on committed activation/tap payment, freeze exact Mount/Vehicle as untargeted event object, preserving buffs even if crew/saddle ability countered.
- [ ] **graveyard-self-cast-additional-cost**: Wickerfolk needs persistent self graveyard cast permission with normal mana plus 2 life and artifact-or-creature sacrifice only when casting through this permission. Existing temporary general permissions and global spell AdditionalCost must not apply costs to hand casts or unrelated permission casts.
- [ ] **exhaust_event**: Dispatch committed exhaust events to battlefield and graveyard observers; include mana exhaust and suspended mana funding without double firing on replay; exclude copies/failed activations
- [ ] **exhaust_discount**: Typed generic reduction on exhaust activations of other controlled permanents, applied consistently to real and speculative costs
- [ ] **exhaust_refueler**: Per-player actual exhaust-activated-this-turn history plus own-turn as-though spent-exhaust permission, not clearing lifetime usage
- [ ] **discard_event_amount**: Expose existing DiscardTriggerView.amount through AmountValue rather than use cumulative discarded-this-turn scalar
- [ ] **howler_delayed_hit_draw**: Source-independent until-cleanup observer on exact target combat hit; draw for original resolving controller rather than grant creature-controller draw ability
- [ ] **mount_vehicle_entry_history**: Count successful entries with Mount or Vehicle subtype at event time per controlling player, even before Coordinator enters
- [ ] **filtered_graveyard_departure**: Add artifact-or-creature filter to one-or-more card departure batch trigger preserving frozen observer
- [ ] **speed_scalar_max**: Add current controller speed scalar and max-speed source-grant/trigger condition usable by static/trigger quantity machinery; current StartYourEngines and speed increase are present
- [ ] **graveyard_max_speed_activation**: Max-speed granted activation at graveyard source zone; existing SourceMaxSpeedActivation visitor only traverses battlefield
- [ ] **no_abilities_predicate**: Abilityless-card predicate for graveyard targets and library searches; keyword-free is insufficient because cycling and other nonbattlefield abilities count
- [ ] **library_graveyard_hand_search**: Optional library-and/or-graveyard single-card search to hand with reveal and shuffle only if library searched
- [ ] **global_exile_batch**: Any physical card from either player battlefield/graveyard to exile during own turn triggers once per simultaneous event with proper pre/post observers; existing observer restricted to own creatures
- [ ] **conditional_search_destination**: Library search one artifact to Battlefield ifMV<=2 else Hand; existing conditional library pick is useful implementation but not a search
- [ ] **reanimate_permanent_keywords_own_end**: Attach lasting keyword grant and source-independent next-own-end exile to exact actual reanimation entrant
- [ ] **pirate_vehicle_attack_history**: Combat-local historical declarations record Pirate+Vehicle membership, including one attacker satisfying both, and survive subtype/departure changes
- [ ] **far_fortune_damage**: Max-speed replacement adds1 to any controlled-source damage to opposing player or permanent; existing NoncombatDamageToOpponentPlus excludes combat
- [ ] **event_saddle_animation**: Apply direct saddled and animation effects to exact Subject::Entering/Targets without collecting cost helpers; saddle designation not activated ability
- [ ] **controlled_add_creature_subtype**: Add Ooze subtype to live controlled creatures in layer4 while independent live6/6 base remains in7b
- [ ] **mimeoplasm_entry_linked_copy**: Pre-entry optional exile0..X own creatures, exact linked actual exile result with3 counters each; target linked exile cards and lasting copy0/0 retaining activation; preserve ability origin/use identities
- [ ] **optional_target_hand_discard_draw**: Private look at target player hand followed optional selected discard and draw only when card chosen; no discard choice is legal
- [ ] **oviya_hand_entry_result**: Condition two post-entry counters on exact actual artifact entering from optional filtered hand choice; existing PutHandFiltered lacks generic resulting entrant handle
- [ ] **attacking_opponent_player_keywords**: Keyword grant filters actual attacked player, excluding attacks on planeswalkers/Battles
- [ ] **dynamic_search_maximum**: Use current speed to cap search count at resolution without physical source dependence
- [ ] **choose_graveyard_card_to_hand**: Non-targeted optional choice from entire current own graveyard after mill; existing SelectMilled only exact mill batch
- [ ] **source_counter_parity**: All-counter sum parity including sparse named counters and source-departure LKI for Sab-Sunen second clause
- [ ] **group_base_source_power**: Freeze other controlled creatures and signed source POWER once and set both base axes to it until cleanup
- [ ] **library_until_nth_kind**: Reveal until second matching land instead of current LibraryLook::UntilKinds first match; whole remaining library if fewer
