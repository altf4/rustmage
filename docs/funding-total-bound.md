# Exact funding total-mana bound (issue273)

The existing per-color optimistic bound counts each possible color of a mana filter independently and omits its mana activation payment. For16mixed basics and Three Tree Mascot, proving17generic impossible visited625 states in155.803ms in the debug regression. Mascot itself is correctly once per turn. A total bound rejects this case before any search state is visited (4.813microseconds in the first fixed run). These are isolated test timings, not whole-game throughput.

For each pure mana ability the new bound adds max(0, maximum total production minus minimum total payment over mana_options), multiplied by an upper bound on remaining uses. Tap, sacrifice, once-per-turn and exhaust bound a source to one use; life and existing removable counters bound repeated uses. A genuinely repeatable positive source retains a saturated unbounded upper. Neutral conversion adds no quantity but remains available to the exact color search. Current pool, intrinsic tap mana and each untapped convoke creature also contribute.

This is a necessary condition only. Source guards, sickness, source/additional-cost reservations and shared life/counters across abilities are ignored or counted independently, so they only loosen this bound. A creature counted both for mana and convoke likewise overestimates capacity safely. Closed funding moves do not add sources, untap, replenish counters or gain life. Existing obligations, color bounds, legal moves and exact reachability still decide feasibility. Saturating arithmetic cannot turn a large upper into a rejection; no depth/time/heuristic cutoff is introduced.

Focused tests compare480small funding domains against an exhaustive oracle without optimistic bounds, retain necessary conversion and exact once-per-turn/color limits, cover convoke and reserved-source costs, and exercise finite/positive/neutral production, alternative mana costs, counters/life, and saturated counterfactual pools. Full native and lint evidence is recorded in the PR.
