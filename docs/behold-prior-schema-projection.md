# Prior-schema trace projection for behold and basic land mana

Schema 177 adds next-spell counter protection; active protection is unrepresentable in the prior schema, while an inactive flag is removed during projection. It also introduces the per-player `loyalty_ability_activated_this_turn` observation field, which is removed only when false; true history is unrepresentable in the prior schema. It introduces optional `added_basic_lands`, `effective_basic_lands`, and `suppress_printed_land` fields in serialized subtype overlays. It also introduces behold choice, pending, and cost variants; universal basic-land intrinsic abilities change some borrowed-ability indices, slots, and legal mana actions. These are API changes, not just formatting changes.

The bounded-trace recorder can project a subset of observations to earlier schemas. It validates the JSON recursively, removes only the three optional fields, and retains the original byte order of all other fields. A chosen basic type remains representable when the effective types are exactly that chosen type. A type addition, removal of previously printed land types without an equivalent chosen-type replacement, or a conflicting effective type cannot be expressed by the old subtype overlay. Such a trace is marked `prior_schema_unrepresentable` rather than reported as an equivalent historical hash.

The old borrowed-ability layout assigned offsets using the donor's abilities when acquired; the new layout records compact exact-acquisition identities and splits intrinsic basic-land abilities by color. Current observations do not retain enough acquisition history to reconstruct every old slot or distinguish a prior absence of an ability-free donor link. The recorder therefore marks any retained owned borrowing link, slot registry, graveyard acquisition, or use row as unrepresentable, even when current public views and actions are empty. It also marks any nonempty borrowed-ability view, live borrowed slot, borrowed-ability action, or behold state/action as unrepresentable. It checks both the journal and the complete offered action arrays, including actions that were never chosen. It also conservatively rejects mana-ability actions: old and new definitions can expose the same resource through different indices or action variants. This restriction is deliberately broader than the actual behavior change; it must not be interpreted as evidence that every such trace changed.

The old schema cannot express the new behold pending state, entry replacement choice, or reveal-as-cost route. Dropping those variants or rewriting them to an unrelated old choice would hide behavioral differences. The explicit markers are not passing prior-schema comparisons. Retain the old trace baseline, classify marked or changed traces separately, and use independent rules tests to establish each intentional change before updating a baseline.

Independent evidence should include both players and raw/index branches with restore: Forest and dual-land mana through normal actions and copied or type-changed lands; external mana grants surviving land-type replacement; ability-removal timestamp ordering; exiled and graveyard donor acquisition, transformations and slot nonaliasing; projected versus committed sacrifice, including manifested physical cards and a temporary copy over a manifest; and Countersculpt's behold versus extra-mana routes under taxes, reductions, free casting and invalid witness choices. Validate pending choice and public/hidden witness observations separately. Run the guarded focused tests, fixed-input full release validation and throughput measurements before admitting a card or treating the migration as complete.
