`StaticAbilityFragment::SelfGraveyardCastIf(StatValue)` contributes an immutable permission to the existing `has_graveyard_cast` query. It applies only to an actual card in its owner's graveyard and only to `GraveyardCastKind::Cast`. The condition is evaluated for that owner, irrespective of the object's stale controller field. It neither grants land plays nor flashback costs or destinations. The existing `AnnounceCast` transaction supplies normal mana, timing, target checks, exact incarnation and cost lock. Once announcement has used the permission, a later loss of the predicate does not undo casting. No mutable permission row or public wire field is introduced.
