# Temporary death consumers and Suspect

Issue311 adds nine complete bodies through reusable rules: Galuf's Final Act,
Rabid Attack, Perigee Beckoner, Presumed Dead, Absolving Lammasu, Person of
Interest, It Doesn't Add Up, Reasonable Doubt and Convenient Target. Vincent's
Limit Break remains fully gated pending complete Tiered casting costs and
timestamped base power/toughness support. The other audited incomplete Suspect
consumers remain gated. Inventory is provenance, never execution permission.

Suspect is a sparse owned registry of exact battlefield incarnations, publicly
observable to both players. It persists through cleanup and controller/type
changes, clears on actual departure, and gives menace and a blocking restriction.
Successful return completion designates only the actual returned permanent;
replacement redirection or failure cannot designate a stale object. Unsuspecting
all creatures uses their current characteristics. Clone/restore and logical memory
account for the owned sparse data. The observation schema is91.

Temporary grants reuse actual dying-object LKI, first public graveyard binding,
and the existing exact owner-return machinery. Galuf chooses its optional target
at trigger announcement and uses dying power. Perigee includes both the normal
body and full Warp alternative. Rabid uses incremental distinct choices with a
`usize::MAX` upper bound rather than enumerated subsets or a fixed64 cap. Unknown
printed residuals and parentheticals fail closed. Exact contextual Suspect
reminders are authenticated before composing independent Aura/Role, intrinsic
and graveyard-return guards. No card-name whitelist authorizes execution.

Prototype evidence on parent c023295: all14 existing temporary-grant native
tests pass. Eight new paid native groups cover both seats,70 Rabid recipients,
actual death draw triggers, dying-power counters, owner-return/Suspect, normal
and Warp Perigee, complete Person/Lammasu bodies, counter-payment/Suspect target
groups, and Convenient Target's Aura and grave activation. All eight groups pass
on the corrected fixture. Eleven focused compiler/provenance methods pass,
including declared-nine canonical preservation, exact Detective factory recipe,
renamed/reserved-name positives, unknown raw negatives and140 pinned Java files.

Earlier prototype runs remain failed evidence: Reasonable Doubt's fixture first
looked for the unrelated effect-payment action, then defaulted to declining
instead of explicitly paying the resolution tax; the old malformed-metadata
test incorrectly rejected a valid subtype-free Perigee Creature. Fixes changed
those fixtures, not the runtime. The first raw-guard composition correctly kept
Convenient Target gated until its separately authenticated reminder was accepted
by both intrinsic and graveyard-return guards. Full final composed native,
compiler, public Standard policies and workload gates, dependency composition,
and two independent exact-final reviews remain pending. This draft does not
claim complete Standard support or final validation.

Rules reference: pinned2026-09-25 Comprehensive Rules701.60 (Suspect),702.185
(Warp), and702.183 (Tiered prerequisite); the MKM release notes specify that
Person of Interest still creates its Detective if its source has left, and that
Lammasu's death ability gains life with no chosen target but entirely fails when
its chosen target is illegal. Durable cases for these boundaries are required
before final freeze.
