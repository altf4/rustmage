## Rules and owned state

Each grant binds an exact battlefield incarnation, immutable static program, historical granting source/caster and expiration turn. A sparse optional boxed vector adds one pointer to default state and allocates only while grants exist. Repeated grants remain separate abilities. Both public observations, snapshots and independent clones own their contexts. Logical bytes count the initialized vector and entries. Granted triggers reuse the existing owned attachment context and first-public-source-movement binding, without another per-stack-packet box.

Actual battlefield departure queues granted self-death programs against dying-object LKI before clearing that incarnation's grants. The dying creature's controller controls each trigger. Cleanup expires every grant before cleanup-induced state-based deaths. Bounce/reentry and recycled token slots cannot inherit old grants.

Return uses the exact first public graveyard incarnation, enters tapped under its immutable owner, and never follows a later movement. Undying Malice's counter passes through normal entry-counter replacements before entry. Not Dead After All creates its Wicked Role only on an actual successful battlefield return; the captured death-trigger controller creates it independently of the returning creature's owner/controller. A returned Vehicle that is no longer a creature cannot receive that Aura. Fake Your Own Death's later Treasure instruction still resolves when a response exiles the dead card and return fails.

Strict generic compilation authenticates untouched complete spell rules, signed growth, the exact quoted return clause and any contextual Wicked/Treasure reminder. All other callers retain original raw rules; the remaining Role, quoted-token and target-exclusion guards remain intact. Names and manifests cannot authorize omitted clauses.
