# Temporary creature death grants

Issue299 / draft PR302 implements complete Not Dead After All, Fake Your Own Death and Undying Malice bodies. The pinned eight-card inventory remains evidence, not an execution whitelist. Galuf's Final Act, Perigee Beckoner, Presumed Dead, Rabid Attack and Vincent's Limit Break remain wholly gated pending their complete missing mechanics. The full Standard training/search objective remains incomplete.

Each grant is an exact battlefield incarnation plus immutable static program, historical granting source/caster, and expiration turn. A sparse optional boxed vector adds one pointer to the default state and allocates only while grants exist. Repeated grants remain separate abilities. Public observations expose these public facts to both seats; snapshots and independent clones own them. Logical memory counts the vector header and every initialized grant, rather than capacity. No new per-stack-packet box is introduced: a triggered grant reuses the existing granted-ability context and first public source-movement binding.

Actual battlefield departure queues matching granted self-death programs against dying-object LKI before removing that incarnation's grants. The dying creature's controller controls its trigger; the original spell caster does not substitute. Cleanup expires the registry before cleanup-induced state-based deaths. Bouncing and recasting the same physical card cannot carry a grant to its new incarnation.

A return reads the exact first public graveyard incarnation and enters under its immutable owner, tapped. Undying Malice's counter is an entry counter, processed by the normal counter-replacement transaction before the entering object is committed. Not Dead After All creates its Wicked Role only on an actual successful battlefield return; the captured death-trigger controller creates the token independently of the returning creature's controller. A returned Vehicle that is no longer a creature cannot receive that Aura. Fake Your Own Death's Treasure is a later independent instruction and still happens when a response exiles the dead card before return.

Strict generic compilation authenticates the complete untouched raw spell body, return clause and any exact contextual reminder before applying its grammar. Unknown suffixes, infixes, nested parentheses and split-word residuals remain gated. Names and the provenance manifest do not authorize semantics.
