# Command emblems and historical traces

The Ajani Resolute batch corrected the shared characteristic query so static
power-and-toughness modifiers on command-zone emblems apply. This also changes
potential behavior for Vivien Reid's existing emblem.

A schema-181 projection of the current pool was compared with the previously
recorded 2,918 schema-181 card traces. 2,917 matched exactly; Vivien Reid was
classified as unrepresentable by the conservative guard because its emblem
can carry behavior the prior engine did not implement. This is not evidence of
a changed bounded trace or of equivalence for that exception. The later
same-schema 2,919-trace baseline comparison matched every existing trace.
