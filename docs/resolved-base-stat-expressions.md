Genemorph Imago's complete flying and landfall ability selects a legal target,
then evaluates the controller's current land threshold when the ability resolves.
The resulting fixed 3/3 or 6/6 setter uses the foundation's independent layer-7b

changes do not recalculate the captured value.

Moon Girl and Devil Dinosaur's second-draw trigger independently sets the exact
source to 6/6 and grants trample until cleanup. Its controlled artifact entry draw
uses the existing once-per-turn event tracker. Further draws do not create more
setters or refresh timestamps. Whole-body lowering authenticates both clauses.

Belligerent Yearling's complete trample/optional other-Dinosaur entry ability
reads current signed power when resolving. If the exact entering incarnation
has departed, it reads that incarnation's last-known departure power instead.
It does not clamp negative power or reuse power captured at entry. Later reentry
is a different subject; a returned source is likewise a different recipient.

The typed `ResolvedStatValue` evaluator is distinct from nonnegative quantity
expressions. It currently supports conditional earlier-layer values and signed
event-subject power. Only relevant entry abilities allocate sparse subject facts
inside the existing snapshot-owned RoleState; no always-present Object or
SpellView field was added. Public facts retain only the already-public exact
battlefield incarnation and optional departure power. Before a departure, facts
are captured from the frozen ObjectView; simultaneous transitions already freeze
all such views before moving any object. Current exact objects use their current
stats. Cleanup clears the temporary facts once legal play has exhausted the
stack. Owned heap accounting includes the sparse vector.

The compiler recognizes whole semantic clauses and exact source aliases, never
card-name dispatch. The generic base-stat raw-authentication guard remains
mandatory across callers and rejects unknown reminders and incomplete bodies.
