# Frozen death and entry event contexts

This engine checkpoint establishes four audited TDM shapes using typed fixtures;
it adds no ordinary card definitions or admissions. The paired evidence file
records the complete Oracle/Java authority and exact tested source hashes.

`CreatureDiesWithCounters` includes self and simultaneous controlled deaths.
Each packet owns the dying creature's entire pre-event counter multiset,
including both +1/+1 and -1/-1 counters before state-based annihilation and all
sparse kinds. `PutEventCountersOnTargets` uses the ordinary replacement-aware
counter pipeline. Later source changes, departure refresh and slot reuse cannot
rewrite this immutable event witness. Its sparse owned storage is counted.

`GraveyardUnderControllerOnce` watches one exact permanent until departure or
cleanup and qualifies its controller at departure. The official Desperate
Measures ruling permits loss of creature type, so the existing generic creature
`DiesOnce` clause keeps its separate semantics. The queued packet is counterable.

An explicit graveyard `CreatureDies` observer is indexed before the event.
Already-present observers see each simultaneous death; a source newly moving to
the graveyard does not observe its own event. Existing owned optional mana
payment and exact graveyard return perform the Forebear shape. Leaving the
graveyard or ceasing a copied object releases indexes before slot reuse.

`CreatureEntersYouIfCast` requires entry under the observer's control and the
captured actual caster to be that controller. Tokens/direct entries and another
player's redirected cast do not qualify. `DestroyEntering` uses the exact
untargeted entrant and does not recheck creature type or control; later token
creation remains independent of successful destruction.

The focused target passes19 groups, including paid casts, replacements,
illegal-action rollback and representative owned raw/index/restore outcomes.
Thirty-nine directly affected inherited cases also pass. New public event enum
values require the integrator's common schema/trace acceptance work.
