# Warp and paid exile recasting

Issue [245](https://github.com/altf4/rustmage/issues/245) adds Warp as an alternative hand-casting cost, a counterable delayed triggered ability, and an exact-incarnation exile permission. This author branch is based on main `e532036`; its standalone catalogue contains 1,691 supported Standard cards, 83 token recipes, and observation schema 72. Parallel feature integration may change those totals.

The complete Warp bodies are Bygone Colossus, Eusocial Engineering, Germinating Wurm, Knight Luminary, Red Tiger Mechan, Sinister Cryologist, Starbreach Whale, Weftblade Enhancer, Drix Fatemaker, Mechanozoa, Memorial Team Leader, and Nova Hellkite. Shared typed residual grammar also admits the complete Runaway Boulder and Waylaying Pirates bodies. The authenticated [admission manifest](warp-admissions.json) records all 14 admitted bodies, the other 20 whole Warp bodies that remain gated, and 144 pinned Java source hashes. Unsupported text is never discarded to admit a card.

`AnnounceWarp` moves the hand card to the stack before target and payment decisions. It retains ordinary timing, printed mana value, actual payment, cast events and countering. Only an actual permanent entry registers the delayed ability. At the next end step the ability enters the ordinary stack with its own identity. Countering the spell creates no delayed ability; countering that ability produces no exile permission. Leaving and reentering creates a new incarnation that an older delayed ability cannot follow.

Only actual exile by that delayed ability creates `warped_cards` permission for the card owner. The recorded turn is the actual exile turn. `AnnounceExile` becomes available on a later turn and pays the normal printed cost, with normal timing and targets. The permission follows only that exact exile incarnation. It grants no free cast and no Warp cast from exile. Public observations expose retained permission and scheduled delayed identities symmetrically; payment and private choices remain actor-owned.

The sparse state uses a 48-byte owned box only while needed, with 72-byte delayed records and 24-byte permission records. Clone, snapshot and restore own all continuation data. The native fixture baseline is 8,512 logical bytes, increasing to 8,632 with one scheduled ability; consuming the permission reclaims the box. These logical payload counts exclude allocator overhead and spare capacity. The 100-game native smoke benchmark measured an initial 20,152 bytes, 16 more than the exact Plot parent, roughly 228,788 decisions/second, 158 ns clone and 161 ns restore on this host. This limited workload is not an XMage comparison or a broad Magic throughput claim.
