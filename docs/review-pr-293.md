## Rules and owned state

Its optional sparse owned `source_move` binds the actual triggering movement's first public destination. Source-relative target predicates compare exact incarnations. They do not exclude every incarnation sharing a physical card ID, rebind subsequent departures, or infer a dying observer's source from unrelated events in the batch. Hidden destinations cannot supply public source context. ETB packets already use entering incarnations and allocate no redundant box.

Announcement availability, mode/target enumeration, grouped completion, target validation at resolution, and targeted-library continuations use that same bound source. `state_bytes` includes every owned context in pending, ordered, announcing, stacked and resolving packets. Snapshot/clone branches preserve it independently after parent destruction.
